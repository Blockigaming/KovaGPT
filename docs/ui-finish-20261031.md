## Prepared changes

- The composer has a rounded writing surface, a quiet outer focus treatment, and a separate project/files/plugins tray. Voice occupies the primary action until a draft changes it to Send. The same field treatment extends to Library, image prompts, search, and settings.
- Free has a single Brain/Thinking toggle with blue text and icon when active. Default is the off state. Plus exposes four model levels and Pro seven, with server entitlements retained.
- Application tools require an account. Public information, authentication callbacks, and read-only shared snapshots remain accessible. The chat endpoint rejects anonymous requests before provider dispatch.
- The sidebar supports pointer and keyboard resizing from 240–420px, persisted colors, item visibility/order, recent-chat visibility, and search placement. Search defaults to a magnifier beside the same PanelLeft open/close icon. More and history remain scrollable. Account menus match the trigger's left and right edges. Work is removed from navigation and old Work bookmarks redirect to chat.
- Settings, subscription surfaces, Library cards, image controls, search/discovery, and Continue working use the shared rounded presentation. Appearance changes persist across reloads and the published cross-tab ordering repair is retained. Existing Checkout and Portal authority remains unchanged.
- Real daily usage counters appear as bars. Free receives one fifth of Plus; Pro receives fifteen times Plus. Daily messages/images/uploads are respectively 100/8/10, 500/40/50, and 7,500/600/750. Plus remains $16/month and Pro $80/month. Token and technical limits still apply.
- Personal greetings rotate across visits and new conversations. Suggested prompts and recent conversations are loaded with the welcome layout rather than expanding the main route unnecessarily.
- The conversation checklist aggregates generated results, attached files, recorded web/memory context, and recorded provider activity across turns. Activity appears before Outputs and Sources. Browser tab counts and previews require fresh, validated session observations.
- Share creates an explicitly reviewed text snapshot and copies its real URL. Clipboard failure preserves a selectable link and never produces a false success toast. Links expire in 30 days and can be revoked in Privacy. Email invitations retain their existing flow.
- Public snapshots use a separate service-only `chat_public_shares` table, preserving the older `chat_share_links` table and its grants. Snapshots are immutable, account-exported, fenced during deletion, and removed with their owning Auth identity. Per-owner admission is bounded to 20 live links and 1 MiB, with expired/revoked rows reclaimed on creation. The shared export budget is extended when its canonical foundation is present.
- Image generation/editing uses the existing approved provider binding. Editing defaults on only for a supported model and respects the explicit operator disable flag. Five shapes and validated Custom dimensions are available; provider size capabilities remain authoritative. Main-chat image generation retains its existing authenticated path.
- Help has 156 authored answers and 22,464 combinations of browser/device, connection, and plan checks. This is not a claim of 10,000 independently authored root-cause articles or answers to every future problem.

## Browser integration contract

The browser backend is not connected by this change. A future adapter emits `browser_interact` activity with validated `browser` metadata: `sessionId`, `tabCount`, `observedAt`, and optional same-origin `previewPath` and HTTPS `url`. Observations older than five minutes do not claim a current session. The adapter can use `createToolActivityEvent` and `activityToSseDelta`; it must provide its authenticated preview endpoint. Running activity is not restored as an active session from durable history. Browser screenshots in the review are explicitly synthetic fixtures, not a production session.
