# Scope and intentional exclusions

Updated **2026-09-05**. Exclusion is a product/platform decision or genuine external boundary, not a way to defer missing portable source. See [remaining autonomous gaps](../remaining-chatgpt-gaps.md).

| Item                                                                                                  | Classification                         | Reason and Kova boundary                                                                                                                                                                    |
| ----------------------------------------------------------------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Voice, audio, microphone dictation, read-aloud and recording                                          | Binding intentional exclusion          | The owner explicitly removed these. No mic control or speech pipeline is authorized; a new reference feature does not reopen this scope.                                                    |
| Native macOS/Windows/Linux/iOS/Android applications, CLI/IDE distribution                             | Platform N/A                           | Current delivery is web/PWA. Dedicated binaries, OS entitlements and distribution are not established by responsive layouts or an install prompt.                                           |
| Desktop Computer Use, Computer History, browser extensions/appshots/local folders/Apple Messages/pets | Native capability N/A                  | These require device-level permissions and a native client. Kova's isolated cloud browser, public shell cache and stored Workspace Timeline do not claim device surveillance or OS control. |
| Identical models, private routing/ranking and OpenAI-managed hosting/private APIs                     | Proprietary/external                   | No access to private internals is implied. Kova uses its approved provider lineup and isolated static Sites service. Open protocols and bounded portable workflows remain implementable.    |
| Regulated healthcare/clinician, BAA/HIPAA/FedRAMP, residency or legal-hold guarantees                 | Unsubstantiated claim excluded         | Contracts, operational controls, policy and independent evidence are required. General research, privacy source and audit exports are not certification.                                    |
| GPT-Rosalind/scientific specialist validation and trusted-access cyber/Daybreak                       | Provider/access boundary               | Proprietary model access and validated specialist operating policies are not available through generic Kova credentials. General analysis and code review remain bounded workflows.         |
| Institutional Edu/Teachers deployments and exclusive partner products                                 | External institutional boundary        | School agreements, administration and third-party permissions are distinct from Kova Study and ordinary organization roles.                                                                 |
| Arbitrary user-generated server code, OpenAI D1/R2 internals and desktop repository execution         | Outside reviewed hosting/runtime shape | Current Sites is static and isolated; Work supports fixed terminal/Python tools. Portable authenticated state/analytics remain explicitly reviewed differences, not silently complete.      |
| Unsupported formats, unpurchasable plans, unverified providers and empty route aliases                | Truthfulness boundary                  | Expose only implemented journeys and configured operation semantics; a label is never success or entitlement.                                                                               |
| OpenAI branding/assets/copy/private source or exact trade dress                                       | Original-product boundary              | Preserve Kova branding and functional familiarity without copying proprietary assets or confusing affiliation.                                                                              |
| Private/authenticated/geographically restricted reference surfaces without access                     | Audit limitation                       | Do not bypass controls. Record unobserved variants; supplied authorized access can later enable a lawful check.                                                                             |

The current [official source audit](chatgpt-surface-audit.md) records the reference pages actually read. None of these classifications proves production readiness or changes the 23.2% baseline.
