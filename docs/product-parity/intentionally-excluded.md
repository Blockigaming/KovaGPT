# Intentional exclusions

| Item                                                                                                  | Classification                              | Reason                                                              |
| ----------------------------------------------------------------------------------------------------- | ------------------------------------------- | ------------------------------------------------------------------- |
| Voice pages and voice functionality                                                                   | intentionally excluded                      | Requires separate explicit authorization                            |
| Empty aliases for requested URLs                                                                      | intentionally excluded                      | A route without meaningful functionality would create false parity  |
| Unsupported document/spreadsheet/presentation/site types                                              | unsupported by current Kova infrastructure  | Release only after create, edit, store, render, and export all work |
| Unpurchasable public plans                                                                            | intentionally excluded                      | Public plan must be purchasable or requestable                      |
| Unverified compliance, certification, residency, education, or enterprise guarantees                  | intentionally excluded pending legal review | Claims require implementation and independent verification          |
| OpenAI/ChatGPT logos, icons, illustrations, copy, proprietary code/private APIs, or exact trade dress | legally inappropriate to copy               | Kova must remain an original product and avoid confusion            |
| Authenticated, private, hidden, leaked, geographically restricted, or protected OpenAI surfaces       | intentionally excluded from audit           | Audit is lawful, public, read-only, and does not bypass controls    |
