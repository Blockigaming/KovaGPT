# ChatGPT feature comparison

Updated **2026-09-05**, source snapshot **`1eb7ef53`**. Overall progress is still **23.2%**. The [27-area source/test inventory](feature-parity.md) is authoritative for capability detail; [remaining gaps](remaining-chatgpt-gaps.md) distinguishes autonomous source work, active packages and genuine owner actions. The [official reference audit](product-parity/chatgpt-surface-audit.md) records public documents actually read and applicability limits.

| Surface                                | Current source truth                                                                                                              | Evidence boundary                                                                                                                                                                                                                   |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

No CRDT or live cross-device certification.                                                                                                          |

All surfaces in this snapshot have **unverified final-head hosted, staging and production status** in [the machine-readable ledger](product-parity/capability-audit.json).
