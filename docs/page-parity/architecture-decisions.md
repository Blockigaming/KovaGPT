# Architecture decisions for reconciled source-contract tests

These decisions reconcile source-contract assertions with the deployed August 11, 2026 architecture. They do not change provider routing, credentials, quotas, billing, Azure configuration, or private-data boundaries.

| Previous failing assertion                   | Actual and intended behavior                                                                                                                                                             | Evidence                                                                                              | Security / migration impact                                                                                  | Resolution                                                                 |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| Voice requires `microphone=()`               | Full-duplex provider Voice is disabled; user-triggered local dictation requires same-origin microphone permission.                                                                       | `ChatInput` contains no realtime/full-duplex provider path; security headers use `microphone=(self)`. | Retains same-origin-only browser permission and does not add an AI audio secret.                             | Assert same-origin dictation separately from full Voice exclusion.         |
| Private Lovable packages must be absent      | Checked-in authenticated email webhook and queue routes import the pinned email and webhook packages.                                                                                    | `package.json` and `src/routes/lovable/email/**`.                                                     | Removing packages would break transactional auth email during migration.                                     | Assert that imported runtime packages are pinned.                          |
| Managed AI gateway must be absent            | The provider has two fixed, code-owned URLs: the managed gateway when its server key exists and direct OpenAI rollback otherwise. Arbitrary URL environment overrides remain prohibited. | `src/lib/ai/provider.server.ts`.                                                                      | Preserves the active migration/rollback path; no browser secret or configurable SSRF endpoint is introduced. | Assert both fixed endpoints and continue rejecting URL overrides.          |
| Bun lockfile must be deleted                 | Repository workflows declare both npm and Bun metadata.                                                                                                                                  | `package-lock.json`, `bun.lock`, `bunfig.toml`.                                                       | Deleting a selected lockfile without dependency migration reduces reproducibility.                           | Require npm lockfile v3 and retain the checked-in Bun lockfile.            |
| Provider Voice requires microphone denial    | Local read-aloud uses `speechSynthesis`; dictation is same-origin. Neither calls provider Voice.                                                                                         | `ChatMessage`, `ChatInput`, security headers.                                                         | No provider audio billing or secret is enabled.                                                              | Assert local features and absence of realtime provider calls.              |
| Responses API must never use managed gateway | Both approved provider paths use the Responses-compatible adapter and fixed provider base URLs.                                                                                          | `providerFetch("/responses")`, provider constants.                                                    | Maintains Azure/provider migration compatibility.                                                            | Test protocol plus fixed endpoint allowlist.                               |
| Instant/deep ceilings are 600/4,000          | Current server-owned policy ceilings are 1,200/16,000.                                                                                                                                   | `src/lib/ai/model-catalog.server.ts`.                                                                 | Entitlement and server-side ceilings remain enforced.                                                        | Update stale numeric source assertions.                                    |
| OpenAI must be the only endpoint             | Managed gateway and direct rollback are the two approved OpenAI inference transports.                                                                                                    | Provider constants and server-only key selection.                                                     | No user-selectable endpoint and no browser key.                                                              | Assert fixed allowlist, not one transport.                                 |
| Images must not accept an attachment         | The image page exposed a reference-image picker that did not submit the selected file.                                                                                                   | `src/routes/images.tsx` and image workflow tests.                                                     | Removing the dead control avoids misleading users; server workflow validation remains unchanged.             | Remove the unwired picker until an authorized upload path is implemented.  |
| Both selector files must call `modesForTier` | `ModelSelector` is intentionally a compatibility re-export; `ResponsiveModelSelector` owns entitlement filtering.                                                                        | Both selector modules.                                                                                | One source of truth reduces divergent entitlement UI.                                                        | Assert delegation and filter ownership.                                    |
| No managed credit path anywhere              | Server-only managed inference is an approved fixed path; configurable endpoints remain forbidden.                                                                                        | Runtime scan plus provider constants.                                                                 | Preserves server custody and migration rollback.                                                             | Scan for endpoint escape hatches rather than the approved credential name. |
