# Automatic I UI surface matrix — 2026-09-03

This is the current-source evidence matrix for `codex/automatic-i-ui-finalization`. It is a workstream control document, not a release certificate. It inventories the source-feasible product surfaces required by the Automatic I mandate and separates what is present in the working tree from what has actually been exercised in a browser or verified in production.

## Evidence boundary

- `PASS` in any column other than **Production** means only that the current source and the cited local check support that claim. It does not mean deployed, provider-backed, cross-account, or production-verified.
- `BLOCKED` means one or more of: the capability is intentionally unavailable, a real backend/provider is missing, authenticated or plan fixtures are unavailable, browser evidence is incomplete, a neighboring owned PR must land first, or owner-authorized deployment/live verification is required.
- `N/A` means the state genuinely does not apply; it is not a substitute for missing evidence.
- Every **Production** cell is `BLOCKED`. This run has no authorization to deploy, mutate live data, exercise another person's account, trigger charges, or submit consequential production actions.
- The latest completed broad local browser sample produced **48 passed, 27 intentional skips, and 1 failed**. The failure is the desktop collapsed-sidebar width assertion owned by PR #256. That sample is representative signed-out coverage, not full coverage of every row below. It does not prove signed-in, Free/Plus/Pro, provider, billing, connector, cross-account, or production behavior.
- Light/dark screenshots are limited to representative guest-shell states. A theme token or a static assertion alone is recorded as source evidence, not visual proof.
- The branch had a previously validated checkpoint with formatting, lint, TypeScript, unit tests, integration subsets, and a production build passing. Rows whose tests were added or changed after that checkpoint say **rerun pending** and remain blocked until the current head is revalidated.

### Status shorthand

| Mark | Meaning |
| --- | --- |
| `PASS (source)` | Implemented and supported by a cited source/local check. |
| `PASS (sample)` | Exercised only in the representative local browser sample. |
| `BLOCKED (browser)` | Source exists, but adequate rendered evidence is missing or failing. |
| `BLOCKED (auth)` | Genuine signed-in/cross-account evidence is unavailable. |
| `BLOCKED (tier)` | Genuine plan entitlement evidence is unavailable. |
| `BLOCKED (backend)` | Real durable backend/provider capability is absent or unverified. |
| `BLOCKED (rerun)` | Current working-tree change has a focused test, but its post-change run is pending. |
