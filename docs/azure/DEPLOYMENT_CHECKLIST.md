# Azure production deployment checklist

- [ ] Clean `main` at the intended exact release SHA.
- [ ] Full local source/test gates pass.
- [ ] Production Supabase project reference and browser configuration match.
- [ ] Supabase migration history is reconciled without blind repair.
- [ ] Production backup verified and disposable restore rehearsal passed.
- [ ] ACR image is built from the exact SHA/tree and resolved to `@sha256:`.
- [ ] Azure Bicep compiles and `what-if` is reviewed.
- [ ] Managed identity has only ACR Pull, Key Vault Secrets User, and Azure OpenAI User scopes required.
- [ ] Key Vault secret references are versioned and complete.
- [ ] Production Container App revision is healthy/running and reports the exact SHA.
- [ ] GPT-5.6 Sol streaming and tools pass through the Azure provider path.
- [ ] Scheduled Container Apps Job succeeds and durable task evidence exists.
- [ ] Log Analytics/Application Insights receive health and error telemetry.
- [ ] Cloudflare proxied DNS points to Azure; Full (strict) TLS is enabled.
- [ ] Azure origin allowlist exactly matches Cloudflare ranges; temporary ranges are empty.
- [ ] Production smoke, auth, billing, files/images/research, and two-user isolation pass.
- [ ] Rollback to the previous immutable image is proven.
- [ ] One exact-SHA final GitHub CI run is green.
- [ ] Zero active Lovable dependency is proven in source, build, runtime, DNS, and outbound configuration.
