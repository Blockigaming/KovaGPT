## Very next operator action

In Azure Portal: sign in with **Reader**, select the approved tenant/subscription, open **Container Apps**, and confirm the intended staging app/resource group without changing configuration. Then run:

```bash
az account show --query '{subscription:id,tenant:tenantId,user:user.name}' -o json
az containerapp show -g <STAGING_RG> -n <STAGING_APP> -o json > /tmp/kova-app.json
az containerapp revision list -g <STAGING_RG> -n <STAGING_APP> -o json > /tmp/kova-revisions.json
node scripts/staging-validation/azure-preflight.mjs --metadata /tmp/kova-app.json
```
